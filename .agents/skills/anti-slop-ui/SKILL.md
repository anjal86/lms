# Anti-Slop Professional UI & Design System

This skill guides the agent to build software that looks and feels like it was designed by a world-class product design team at **Linear**, **Attio**, **Stripe**, or **Raycast**, rather than generated by a generic AI template.

---

## 🚫 The "AI Slop" Hall of Shame (Explicitly Forbidden Patterns)

When writing HTML/Tailwind/React/CSS, NEVER produce these tropes:

1. **The Pastel Badge Soup**:
   - ❌ `bg-emerald-50 text-emerald-700`, `bg-blue-50 text-blue-700`, `bg-amber-50 text-amber-700` everywhere.
   - ✅ Single micro 6px colored dot + subtle muted label (`text-zinc-600` / `text-zinc-400`). Color is reserved strictly for acute urgency/status.
2. **Bubbly, Toy-Like Geometry**:
   - ❌ `rounded-2xl`, `rounded-3xl`, `shadow-2xl` on simple dashboard cards.
   - ✅ Sharp, confident radii: `rounded-md` (6px) or `rounded-lg` (8px). 1px crisp borders (`border-zinc-200` in light mode, `border-zinc-800` in dark mode).
3. **Low-Density Puffy Spacing**:
   - ❌ Giant 24px padding on tables and list items where you can only view 4 items per screen.
   - ✅ High-density operational data tables with compact 32px–40px row heights, crisp column dividers, and monospace tabular data.
4. **Distracting Clutter**:
   - ❌ Huge icons in colored square boxes (`w-11 h-11 bg-teal-100 rounded-2xl flex items-center justify-center -rotate-45`).
   - ✅ Functional, subtle 14px–16px icons with uniform stroke width (1.5px) inline with text.
5. **Clunky Centered Modals**:
   - ❌ Popping up a giant centered card for quick edits or logs.
   - ✅ Slide-over Flyout Drawers (Sheet) or Split-Pane inspector that preserves the user's workflow context.
6. **Generic Default Palette**:
   - ❌ Default Tailwind `slate` everywhere with bright blue/teal buttons.
   - ✅ Neutral monochromatic base (Zinc scale: `zinc-950`, `zinc-900`, `zinc-800`, `zinc-200`, `zinc-100`, `zinc-50`) with an intentional, restrained accent.

## 🏛️ The Attio / Linear Design Tokens

### 1. Color System (Zinc Monochromatic)
```css
/* Light Mode */
--surface-bg: #fafafa;         /* zinc-50 */
--surface-card: #ffffff;       /* white */
--surface-subtle: #f4f4f5;     /* zinc-100 */
--border-subtle: #e4e4e7;      /* zinc-200 */
--border-contrast: #d4d4d8;    /* zinc-300 */
--text-primary: #09090b;       /* zinc-950 */
--text-secondary: #52525b;     /* zinc-600 */
--text-muted: #71717a;         /* zinc-500 */
--text-disabled: #a1a1aa;      /* zinc-400 */

/* Dark Mode */
--surface-bg: #09090b;         /* zinc-950 */
--surface-card: #121215;       /* zinc-900 elevated */
--surface-subtle: #18181b;     /* zinc-900 */
--border-subtle: #27272a;      /* zinc-800 */
--border-contrast: #3f3f46;    /* zinc-700 */
--text-primary: #f4f4f5;       /* zinc-100 */
--text-secondary: #a1a1aa;     /* zinc-400 */
--text-muted: #71717a;         /* zinc-500 */
```

### 2. Status Dot Standard (No Badge Soup)
Instead of pill badges:
```tsx
// ❌ AI Slop:
<span className="bg-emerald-100 text-emerald-800 text-xs px-2.5 py-1 rounded-full font-bold">
  Available
</span>

// ✅ Modern Pro:
<div className="inline-flex items-center gap-1.5 text-xs font-medium text-zinc-600 dark:text-zinc-300">
  <span className="w-1.5 h-1.5 rounded-full bg-emerald-500 ring-4 ring-emerald-500/10" />
  <span>Available</span>
</div>
```

### 3. Typography & Hierarchy
- **Font**: Inter, Geist, or system font stack with high tracking control.
- **Micro-labels**: `text-[11px] font-medium tracking-tight text-zinc-500 uppercase`.
- **Numbers / Metrics / Currency / Dates**: `font-mono tracking-tight font-medium`.
- **Headings**: `text-base font-semibold tracking-tight text-zinc-900` (Avoid oversized `text-3xl font-black` everywhere).

### 4. Layout & Interaction Patterns
- **High Data Density**: Tables with compact rows (`h-9` or `py-2`), horizontal border dividers (`border-b border-zinc-200/80`), subtle row hover (`hover:bg-zinc-50/80`).
- **Keyboard Shortcuts**: Include visible subtle shortcut badges (e.g. `<kbd className="px-1.5 py-0.5 text-[10px] font-mono bg-zinc-100 border border-zinc-200 rounded">⌘K</kbd>`).
- **Flyout Drawers**: Use a right-hand slide-over drawer (380px–480px) for entity inspection (Lead detail, Quick notes) so the table remains visible in background.
- **Button States**:
  - Primary: `bg-zinc-900 text-zinc-50 hover:bg-zinc-800 active:bg-zinc-950 dark:bg-zinc-100 dark:text-zinc-900 shadow-xs text-xs font-medium px-3 py-1.5 rounded-md`
  - Secondary: `bg-white dark:bg-zinc-900 border border-zinc-200 dark:border-zinc-800 hover:bg-zinc-50 dark:hover:bg-zinc-800/60 text-zinc-700 dark:text-zinc-200 text-xs font-medium px-3 py-1.5 rounded-md shadow-2xs`
  - Ghost: `hover:bg-zinc-100 dark:hover:bg-zinc-800 text-zinc-600 dark:text-zinc-400 text-xs font-medium px-2 py-1 rounded-md`

## 🛠️ Refactoring Checklist

When upgrading an existing component from AI slop:
1. [ ] Replace `rounded-2xl` and `rounded-xl` with `rounded-md` or `rounded-lg`.
2. [ ] Replace bright multi-colored badge pills with micro status dots + neutral text.
3. [ ] Replace loud gradient cards with crisp 1px bordered zinc surfaces.
4. [ ] Increase data density: tighten padding from `p-6` down to `p-4`, and table cells down to `py-2 px-3`.
5. [ ] Apply monospace font to codes, timestamps, phone numbers, and currency values.
6. [ ] Replace disruptive centered dialogs with a slide-over flyout inspector where appropriate.
